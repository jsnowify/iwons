## Ribbon runs: Proof strip

A sticking key leaves repeated marks across a typewriter ribbon's inspection strip. Sol rolls a fresh proof strip into the office typewriter. The supervisor wants the readings in their precise working order before signing the file.

A run is a maximal consecutive group of identical characters. Produce its length for each run, from left to right. Spaces are characters too.

Return the entire derived sequence, preserving its order.

Implement ribbonRunsProofStrip(line, k). k is part of the common inspection-card signature and does not affect this task's result.

## Ribbon runs: Boss receipt

Return the weighted sum of the derived sequence: multiply its first value by 1, its second by 2, and so on, then add the products. Return 0 for an empty sequence.
