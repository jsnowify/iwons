# Feedback voice

Praise a choice, strategy or useful check, never intelligence. Treat errors as information. Every unsuccessful interaction gives a specific next action. Keep compiler/runtime diagnostics verbatim, introduced by a helpful framing sentence. Never infer ability, honesty, confidence or learning from time spent alone.

| Situation | English | Tagalog (draft) | Bisaya (draft) |
| --- | --- | --- | --- |
| Correct prediction | Your trace matches the output. Run the example to check the next change. | Tugma ang trace mo sa output. I-run ang example para tingnan ang susunod na pagbabago. | Nagtakdo ang imong trace sa output. I-run ang example aron susihon ang sunod nga kausaban. |
| Recall miss | Not yet. Follow the highlighted line, then try recalling it again. | Hindi pa. Sundan ang naka-highlight na linya, tapos subukang alalahanin ulit. | Dili pa. Sunda ang gi-highlight nga linya, unya sulayi paghinumdom pag-usab. |
| Compiler/type error | The program needs a change before submission. Start with the first reported line below. | May kailangang baguhin bago mag-submit. Magsimula sa unang linyang nakasaad sa ibaba. | Naay usbon sa program sa dili pa mag-submit. Sugdi sa unang linya nga gipakita sa ubos. |
| Successful solve | Your program passes these checks. Explain one choice you made, or continue to the next exercise. | Pasado ang program mo sa mga check na ito. Ipaliwanag ang isang pinili mong paraan, o magpatuloy sa susunod na exercise. | Nakapasar ang imong program sa mga check. Ipasabot ang usa nimo ka pagpili, o padayon sa sunod nga exercise. |

Explain to Tik is optional private writing, never AI graded. Watch does not receive explanation text, confidence taps or recall responses. Translations require native-speaker review.
